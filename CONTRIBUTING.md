# Contributing to `gif2ascii` 🎬✨

Thank you for your interest in contributing to `gif2ascii`! We welcome bug reports, feature requests, documentation improvements, and code contributions from the community.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
If you encounter a bug, broken line wrapping, or unexpected behavior:
1. Check existing [GitHub Issues](https://github.com/TIXIANO70/gif2ascii/issues) to see if it has already been reported.
2. If not, open a new Issue providing:
   - Your terminal emulator (e.g. Kitty, Foot, Alacritty, WezTerm).
   - Your OS environment (Linux distro, macOS).
   - Steps or GIF file to reproduce the issue.

### 2. Suggesting Features
Have an idea for a new rendering mode, preset, or TUI enhancement? Feel free to open an Issue with the `enhancement` label!

### 3. Pull Requests (PRs)
1. **Fork the Repository**:
   ```bash
   git clone https://github.com/TIXIANO70/gif2ascii.git
   cd gif2ascii
   ```
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/my-cool-feature
   ```
3. **Make Your Changes & Test**:
   Test rendering, preset loading, and TUI menus before committing.
4. **Commit & Push**:
   ```bash
   git commit -m "feat: add my new feature"
   git push origin feature/my-cool-feature
   ```
5. **Open a Pull Request**: Submit your PR on GitHub with a clear description of your changes!
